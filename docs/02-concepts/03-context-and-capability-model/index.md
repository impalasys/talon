Talon distinguishes durable context from the capabilities an agent may activate or execute.

## Relationship map

Sessions supply history, Files supply durable context and artifacts, Skills package reusable instructions, and policy-controlled tools or sandboxes supply executable capability.

## Read in order

1. [Memory, Files, and Artifacts](/talon/docs/concepts/context-and-capability-model/memory-files-and-artifacts)
2. [Skills](/talon/docs/concepts/context-and-capability-model/skills)
3. [Tools, MCP, and Sandboxes](/talon/docs/concepts/context-and-capability-model/tools-mcp-and-sandboxes)

Start with Memory, Files, and Artifacts to understand durable context, then continue to Skills and tools for execution capability.
